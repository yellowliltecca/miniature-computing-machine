# Сайт автосервиса — Энгельс, Степная 66 к1

Статический адаптивный сайт без сборщика, фреймворков и сторонних библиотек.

## Файлы
- `index.html` — структура страницы
- `styles.css` — оформление и адаптивность
- `script.js` — просмотр фотографий в увеличенном виде
- `assets/` — оригинальные фотографии, переданные заказчиком

Фотографии скопированы без изменения размера и без повторного сжатия.

## Запуск
Откройте `index.html` в браузере.

## Публикация на GitHub Pages
1. Создайте репозиторий GitHub.
2. Загрузите в него все файлы и папку `assets` (не только `index.html`).
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку `main` и папку `/ (root)`, затем Save.
